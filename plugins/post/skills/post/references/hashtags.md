# Hashtags (the 2026 reality)

**Hashtags are not a reach hack.** Platforms now understand content directly (caption, on-screen text,
spoken audio, visuals, engagement), so tags mostly **categorize** a post and **aid search**. Set this
expectation with the owner up front, then spend most of the effort on keywords and the content.

- Instagram removed hashtag following (Dec 2024) and **enforces a 5-hashtag cap** (rolled out Dec 2025);
  more are blocked or trimmed. Its head has said more tags do not mean more reach.
- #fyp / #viral / #explore do nothing for placement.
- "Same block = shadowban" is unconfirmed; the real risks are irrelevant tags and spam-associated tags. Rotate
  anyway: one pasted block is imprecise and reads as low-effort.

## Order of work

1. **Keyword / social-SEO layer first** (the real lever). Pick the primary keyword the audience actually
   searches plus a couple of variations, and place it where platforms index: the caption front (first ~80
   chars carry most weight), on-screen text, and spoken audio. On TikTok the "triple mention" (say it, show
   it, caption it) is the core ranking move.
2. **A tight, relevant tag set per platform**, within caps.
3. **Branded / campaign tag** where community, UGC or tracking applies.
4. **Rotate** 2-4 sets per pillar; place tags in the caption (best for search on most platforms).

## How many, per platform

Re-verify quarterly; caps move without notice.

| Platform | Count | Hard cap | Notes |
|---|---|---|---|
| Instagram | 3-5 | **5** (enforced) | caption placement; Reels lean on trending audio + keywords |
| TikTok video | 3-5, treated as keywords | - | one broad + niche tags matching real searches (`#BestBudgetLaptop`, not `#Tech`); avoid 30-tag sprays |
| TikTok Photo Mode | 1-2 | never more than 5 | overlay keywords carry the SEO |
| LinkedIn | 3-5 specific, at the end | - | a light topic signal; keywords in the body matter more |
| X | 0-2, often zero | - | one tag only to join a live conversation |
| Threads | **1 topic tag** | 1 | pill-style topic tags, not hashtags; niche consistency matters |
| Facebook | 1-2 at most | - | largely ineffective |
| YouTube | a few | - | keywords in title/description drive search; the first ~3 hashtags can show above the title; tags field: first tag = exact primary keyword, relevant-only |
| Pinterest | 0-2 (or none) | - | **keywords in title and description, not hashtags**; hashtags are deprioritized |
| Bluesky | a few | - | supported but barely used |

## Tag types (mix 2-3 per post, not all eight)

Topic (`#ProductManagement`), niche/community (`#BuildInPublic`), branded (unique to you), campaign
(time-bound launch/event), product/service, location (strong for local), format (`#Tutorial`, sparingly),
event/seasonal (live moments only).

## Research and vetting

1. **Relevance first** - the tag must match the actual content.
2. **Aim mid-tier (~10K-500K posts)** - mega-tags bury you in seconds; tiny tags have no audience.
3. **Check the tag page** - are top posts like yours, with real engagement, not bots or spam?
4. **Skip banned / spam-associated tags.**
5. **Find them natively** - platform search and suggestions, and what well-performing accounts in the niche
   use (analyze, do not copy a list wholesale).

Branded/campaign tag rules: unique and unused (search first), short and typo-safe, on-brand, promoted in
bio/caption/CTA, tracked via native search.

## Pinterest is keywords, not hashtags

Research real queries with Pinterest's autocomplete, Guided Search bubbles and Trends (the owner runs these
natively; never fabricate search volume). Pick long-tail (3+ words) phrases and layer them: profile (broad)
-> board title/description (topic) -> pin title, description, overlay text, alt text, file name
(long-tail). No keyword stuffing; over-optimization is suppressed.

## Measurement

There is no hashtag analytics in the publish route. Point the owner to native insights (for example
Instagram's per-post reach from hashtags) and treat tag choices as experiments to observe. Never claim
performance data that was not read from the platform.
